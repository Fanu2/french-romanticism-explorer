# JASS French Romanticism — Text Explorer

A local-first PySide6 desktop explorer for the JASS French Romanticism full-text SQLite database.

## Included
- Victor Hugo
- Alphonse de Lamartine
- Alfred de Musset
- Alfred de Vigny
- 551 retained poems
- SQLite FTS5 full-text search
- Author and poem browsing
- Reading pane
- Previous/Next navigation
- Copy text
- Font size controls
- Dark/Light theme
- Original database text preserved

## Run on Windows

```powershell
py -m pip install PySide6
py french_romanticism_text_explorer.py
```

Keep `JASS_French_Romanticism_Text.db` beside the Python script.
